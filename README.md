# 👁️ Face Detection with Python

A simple face detection application built using Python and computer vision techniques.
This project was developed for study purposes, focusing on understanding how real-time face detection works.

# 📌 About the Project

This application uses computer vision to detect human faces in real time through a webcam feed.

It was created to explore:

Image processing fundamentals
Face detection algorithms
Real-time video capture
Practical applications of Python in Computer Vision

# 🛠 Technologies Used
Python
OpenCV
Haar Cascade Classifier

# ⚙️ How It Works
The program accesses the webcam.
Each frame is converted to grayscale.
A face detection model scans the image.
Detected faces are highlighted with bounding boxes in real time.
