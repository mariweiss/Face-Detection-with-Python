# <h1 align="center"> 👁️ Face Detection with Python </h1>

<p align="center">
  A simple face detection application built using Python and computer vision techniques.
This project was developed for study purposes, focusing on understanding how real-time face detection works.
</p>

---

# <h1 align="center"> 📌 About the Project </h1>

<p align="center"> This application uses computer vision to detect human faces in real time through a webcam feed.

It was created to explore:

- Image processing fundamentals
- Face detection algorithms
- Real-time video capture
- Practical applications of Python in Computer Vision
</p>

# <h1 align="center"> 🛠 Technologies Used </h1>
<p align="center">- Python
- OpenCV
- Haar Cascade Classifier </p>

# <h1 align="center"> ⚙️ How It Works </h1>
<p align="center">- The program accesses the webcam.
- Each frame is converted to grayscale.
- A face detection model scans the image.
- Detected faces are highlighted with bounding boxes in real time. </p>
